# Image assets

Drop renders into this folder with these exact filenames — the site picks
them up automatically (no code changes needed). Use `.jpg` or `.png`;
both work (the site tries `.jpg` first, then `.png`). JPG ~80% quality,
max ~2560px wide, is recommended — much smaller files, faster loads.

| Filename            | Used in                                          | Status   |
| ------------------- | ------------------------------------------------ | -------- |
| `hero-district.jpg` | Three.js hero, master plan, closing CTA          | required |
| `amphitheater.jpg`  | Precinct 01 — The Amphitheater                   | required |
| `scarlet-spine.jpg` | Precinct 02 — The Scarlet Spine                  | pending  |
| `hotel-tower.jpg`   | Precinct 03 — Buckeye Tower                      | pending  |
| `riverfront.jpg`    | Precinct 04 — The Riverfront                     | pending  |

Until a pending image is added, its panel shows a styled
"render coming soon" placeholder.
